# Advanced ATC

Advanced ATC (AATC) is a ai-based atc replacement for MSFS 2020 and MSFS 2024. \
It can import flight plans from SimBrief and provides realistic ATC communications using AI. \
There is currently no text-to-speech but it will be added in the future.

## Setup

1. Clone the repo

```bash
$ git clone https://github.com/cyteon/aatc && cd aatc
```

2. Install dependencies

```bash
$ bun install
```

3. Move .env.example to .env and populate the necessary fields
4. Run the application with `bun .` then launch MSFS
